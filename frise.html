Guide d'utilisation

🖱️ Navigation & Clics

  • Se déplacer : Cliquez et glissez sur le fond de la frise pour naviguer horizontalement.
  • Ajouter un élément : Cliquez sur "+ Ajouter" ou double-cliquez directement sur l'axe de la frise.
  • Modifier / Supprimer : Double-cliquez sur une carte existante, un point, ou le symbole zig-zag d'une césure.

✋ Glisser-Déposer (Drag & Drop)

  • Déplacer un événement : Cliquez et maintenez une carte pour la déplacer horizontalement (sa date s'aimantera automatiquement selon sa précision) ou verticalement (pour ajuster son éloignement de l'axe).
  • Redimensionner l'image : Attrapez le petit repère dans le coin inférieur droit de l'image d'une carte pour la redimensionner librement.

⏱️ Les Césures

  • Une césure permet de créer un saut dans le temps (ex: masquer une période sans événement). L'échelle se contractera mathématiquement et un zig-zag apparaîtra sur l'axe.

💾 Sauvegarde & Export

  • Sauvegarder : Télécharge un fichier de sauvegarde .json sur votre ordinateur contenant toutes vos données.
  • Ouvrir : Recharge une frise précédemment sauvegardée.
  • Export PNG / PDF : Génère une image ou un document de haute qualité qui inclut automatiquement le logo, le titre et les informations de l'élève.
